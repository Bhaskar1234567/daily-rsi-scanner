PREVIOUS-DAY BOX 3M DASHBOARD SCANNER

Requirements:
1. Python 3.10 or newer
2. Internet connection
3. Windows/macOS/Linux computer
4. No Binance API key is required for the current scanner because it uses public market data.
5. No pip packages are required; the program uses Python standard-library modules.

Run:
python previous_day_box_dashboard_scanner.py

The scanner can continue running 24/7 while the computer/VPS and internet connection remain active.
